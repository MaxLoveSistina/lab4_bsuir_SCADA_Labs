# Лабораторная работа 4. Вариант 8: станция поддержания давления

Цепочка обмена:

```
model.js (Modbus TCP :1502) → arOPC (OPC UA :4842) → SCADA (веб, :8080) → PostgreSQL
              ↑ MQTT-брокер (:1883): уровень в топик lab4/variant08/level
```

SimpleSCADA в работе недоступна, поэтому вместо неё используется собственный клиент OPC UA
(`scada/`): мнемосхема, управление, аварии с квитированием, архив в PostgreSQL, тренд.

## Что запускается в Docker, а что нет

| Компонент | Где | Порты |
|---|---|---|
| PostgreSQL 17 | Docker | 5433 на хосте (5432 внутри сети Docker) |
| MQTT-брокер (`mqtt-broker.js`) | Docker | 1883 |
| Модель (`model.js`) | Docker | Modbus 1502, статус http://127.0.0.1:4004/status |
| SCADA (`scada/server.js`) | Docker | http://127.0.0.1:8080 |
| **arOPC** | **Windows, вручную** | OPC UA 4842 |

arOPC работает только под Windows и в контейнер не помещается. Его нужно установить и настроить отдельно (см. ниже).

## Запуск

1. Установить Docker Desktop и запустить его.
2. В папке `Code/Variant_08`:
   ```
   docker compose up --build
   ```
3. Настроить и запустить arOPC (раздел ниже). Порядок не важен: SCADA сама переподключается.
4. Открыть http://127.0.0.1:8080. Вверху должно быть: «arOPC: связь есть», «PostgreSQL: подключена».

Остановка: `docker compose down`. Полная очистка вместе с архивом: `docker compose down -v`.

## База данных

| Параметр | Значение |
|---|---|
| СУБД | PostgreSQL 17 |
| Хост | 127.0.0.1 (из Docker-сети: `db`) |
| Порт | 5433 с хоста (5432 внутри Docker) |
| База | `lab4` |
| Пользователь | `lab4` |
| Пароль | `lab4local` |

База и пользователь создаются контейнером автоматически, таблицы `history` и `events` создаёт SCADA при старте.

Проверка с хоста:
```
psql -U lab4 -h 127.0.0.1 -p 5433 -d lab4 -c "SELECT tag, count(*) FROM history GROUP BY tag;"
```

## Настройка arOPC (10 тегов)

**Канал** (Конфигурация → Каналы → Ethernet клиент):

| Поле | Значение |
|---|---|
| Название | `ModelTCP` |
| IP адрес | `127.0.0.1` |
| Порт | `1502` |
| Таймаут, мс | `1000` |
| Период соединения, мс | `30000` |
| Флажки | «Разрешить доступ по OPC», «Разрешить опрос устройств» |

**Устройство:** тип Modbus, имя `StationV8`, Modbus ID `1`, основной канал `ModelTCP`.
**Группа:** `Process`. Период опроса всех тегов 1000 мс.

| Тег | Тип | Область | Адрес | Доступ |
|---|---|---|---|---|
| `Pressure` | Float | HOLDING REGS | 0 | чтение |
| `Level` | Float | HOLDING REGS | 2 | чтение |
| `PumpStartSetpoint` | Float | HOLDING REGS | 4 | чтение |
| `PumpStopSetpoint` | Float | HOLDING REGS | 6 | чтение |
| `AlarmPressureLimit` | Float | HOLDING REGS | 8 | чтение |
| `AutoMode` | Bool | COILS | 0 | чтение и запись (FC05) |
| `PumpCmd` | Bool | COILS | 1 | чтение и запись (FC05) |
| `PumpRunning` | Bool | COILS | 2 | чтение |
| `PumpBlocked` | Bool | COILS | 3 | чтение |
| `AlarmHighPressure` | Bool | COILS | 4 | чтение |

Имена тегов должны совпадать точно, SCADA ищет их по имени.

**OPC UA:** порт `4842`, политика None, режим None, анонимный доступ. Затем перевести arOPC в режим исполнения (▶).

Порядок байтов Float: по методичке ABCD (формат тега `0123`). Если arOPC всё же отдаёт перевёрнутые числа (например, 60 как 4e-41), SCADA автоматически разворачивает их и пишет предупреждение в лог.

Если arOPC слушает только localhost и контейнер `scada` не может подключиться (`host.docker.internal:4842`),
разрешите внешние подключения в arOPC или запускайте SCADA локально:
```
cd scada && npm install && node server.js
```
(для этого нужны `DB_HOST=127.0.0.1` и порт БД 5433, либо локальный PostgreSQL на 5432).

## Отправка уровня по MQTT

Модель получает уровень из MQTT (топик `lab4/variant08/level`, значение 0-100 числом или `{"level":45.5}`).
Подключиться клиентом (MQTTX, MQTT Explorer) к `127.0.0.1:1883` и отправить, например, `10`.
Без отправки уровень по умолчанию 60 %.

## Сценарии проверки

1. **Норма:** насос включается при давлении ≤ 300 кПа и выключается при ≥ 500.
2. **Блокировка по уровню:** отправить в MQTT `10` → `PumpBlocked = 1`, насос остановлен; вернуть `60`.
3. **Авария по давлению:** выключить автоматический режим, включить «Команда насосу» → давление > 700 кПа → авария, квитирование.
4. **Отказ источника:** `docker compose stop model`, затем `docker compose start model` (потеря и восстановление связи фиксируются в списке событий).
5. **История:** набрать ≥ 5 минут данных, перезапустить `scada` (`docker compose restart scada`), открыть тот же интервал в блоке тренда.
